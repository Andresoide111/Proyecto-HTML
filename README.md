# Proyecto-HTML
Proyecto en grupo para la clase de programacion para internet

## Estructura

- `Index.html`: página principal del catálogo.
- `pages/`: páginas de checkout, carrito e inicio de sesión.
- `components/`: fragmentos reutilizables de encabezado y pie de página.
- `css/`: hojas de estilo.
- `assets/`: imágenes e iconos.
